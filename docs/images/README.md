## Capture guidance

- Use sanitized demo data only.
- Crop browser chrome only when it does not remove useful workflow context.
- Avoid API keys, bearer tokens, private documents, personal information and provider responses.
- Prefer a consistent viewport and light/dark theme across the final portfolio set.
- Update the root README status whenever a partial or placeholder capture is replaced.
